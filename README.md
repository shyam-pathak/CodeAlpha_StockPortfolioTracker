## Project Description

This project is a simple Stock Portfolio Tracker developed using Python.

The application allows users to enter stock names and quantities. It calculates the total investment value using predefined stock prices stored in a dictionary.

## Features

* Displays available stocks and their prices
* Accepts stock names and quantities from the user
* Calculates total investment value
* Uses dictionary data structure for efficient stock price lookup
* Simple and user-friendly console interface

## Technologies Used

* Python
* Dictionary
* Loops
* Conditional Statements
* User Input Handling

## How to Run

1. Open the project folder.
2. Run the Python file.
3. Enter the number of stocks you own.
4. Enter stock names and quantities.
5. View the total investment value.
